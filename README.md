# Nexora AI

### Self-hosted AI platform with web, API and Android components

**Project under construction**

Nexora AI explores private AI infrastructure for programming assistance, backend workflows, Android development and defensive security tasks. The repository includes application code, server integration and deployment tooling.

## Components

- Native Android client using Kotlin and Jetpack Compose.
- Web interface and API components built with Next.js and TypeScript.
- Optional local model integration through Ollama.
- Native Android integration experiments.
- VPS deployment and configuration scripts.
- Automated build and validation workflows.

## Technology

Kotlin · Jetpack Compose · C/C++ · Next.js · TypeScript · Docker · Ollama · Linux · GitHub Actions

## Development

The project contains several independently configurable services. A successful build does not imply that an externally hosted API or AI model is currently available.

## Security

Use your own credentials and review server access before exposing an installation to the Internet. Do not commit API keys or model-service tokens.
